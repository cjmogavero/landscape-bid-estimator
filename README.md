# Landscape Bid Estimator

A local prototype for preparing landscape bids and comparing nursery quotes by total delivered cost.

## Intended capabilities

- Build an estimate from quantities and unit prices, with overhead and a target profit margin.
- Flag incomplete cost lines before calculating an estimate.
- Compare nursery quotes side by side, including delivery costs.

The goal is to help landscape estimators organize pricing inputs and compare supplier costs. Review all inputs against supplier quotes and bid documents before relying on an estimate.

## Project status

This repository currently contains project documentation only; it does not include an executable application, sample data, or setup instructions. The capabilities above describe the prototype's intended scope and should not be read as a claim that a runnable estimating tool is available here.

## Product direction

The prototype was developed with AI assistance. The maintainer directed product decisions about which costs an estimator needs to capture and how worksheets should surface missing information.
